## Slice M1-01：Work ledger contracts and state machine

### 已实现

| 能力 | 位置 | 合同 |
| --- | --- | --- |
| contrib package | `contrib/agentseek-work` | 独立 Bub entry point；不放入 `agentseek-enterprise`。 |
| `WorkStatus` | `models.py` | 覆盖 draft、queued、running、四类 waiting、succeeded、failed、cancelled。 |
| `WorkItem` | `models.py` | 不可变快照；固定 Profile/Pack/Playbook/runtime/角色/预算/idempotency/version。 |
| `WorkEvent` | `models.py` | 不可变状态事件；记录 actor、phase、from/to status、work version、digest 和 policy decision。 |
| `WorkBudget` | `models.py` | 固定模型、Token、外部查询、phase、任务时长和重试上限。 |
| 状态机 | `state_machine.py` | 只允许 M0 冻结状态边；非法边 fail closed。 |
| 乐观并发 | `state_machine.py` | 调用方必须提供 `expected_version`；陈旧版本拒绝。 |
| attempt | `state_machine.py` | 进入 `running` 才增加 `phase_attempt`；waiting 回队列不增加。 |

### 状态边

```text
draft -> queued | cancelled
queued -> running | failed | cancelled
running -> waiting_external | waiting_input | waiting_review | waiting_approval
running -> succeeded | failed | cancelled
waiting_external -> queued | failed | cancelled
waiting_input | waiting_review | waiting_approval -> queued | cancelled
succeeded | failed | cancelled -> terminal
```
