Playbook 和确定性路由属于 M2/M3。

## 二、运行路径

企微消息先经过既有身份与 Work 状态装配，再进入 LangChain `RunnableSpec`：

```text
WeCom callback
-> enterprise identity
-> Work Profile authorization
-> Job Charter exact matcher
   -> matched: server-rendered response
   -> unmatched: existing DeepAgent path
```

`RunnableSpec.direct_response` 同时支持 invoke 和 stream。命中时不构建 Agent
输入、不调用模型，也不暴露工具。未命中时原有模型、工具和 Output Guard 路径不变。

Job Charter 只接受有限的精确命令。带业务任务的复合消息、天气等无关请求和
`我是谁` 都不会被截获。企微信封只有在具备可信 `channel=$wecom` 与日期标记时
才会被剥离。
