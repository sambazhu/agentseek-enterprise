## 4. 缺陷清单（本轮新增，按优先级）

1. **P1 路由过度拦截缺陷族**：active 态下自然语言（需求修改/组合问句/防泄漏探针/取消）被 NO_MATCH 澄清拦截——**渐进澄清的回复通道被堵死**，与 M2 合同冲突。子串匹配（intent_terms）无法覆盖自然表达（如"证券行业数字化转型研究报告"不含"证券行业报告"子串）。绕行=显式服务前缀。
2. **P1 取消状态机不可达**：repository.cancel_work 从未暴露为工具/消息处理器，而工作上下文宣称 allowed_next_actions 含 cancel——用户无任何途径取消任务（本轮测试任务因此遗留）。
3. **P1 DeepSeek 官方 API 结构化输出不兼容**：with_structured_output 默认 json_schema response_format 被拒（API 原文在案+最小复现）；初稿生成链必需结构化输出→模型切换后 D5 死于此。需上游适配（method=function_calling 或 json_object）或换支持 json_schema 的端点。
4. **P2 澄清分支不列服务**：NO_MATCH 时候选空→提示语"请明确选择一个："后无任何选项（用户须另问"你能做什么"）。
5. **P2 模型配置面混乱**：见 §2（6-7 键/三层优先级/双格式）。
6. **观察**：WORK 首次启用需手动 schema 初始化（AUTO_MIGRATE=false 时无引导错误提示只报 rev 不匹配）；welcome 文案未随归属定制。
