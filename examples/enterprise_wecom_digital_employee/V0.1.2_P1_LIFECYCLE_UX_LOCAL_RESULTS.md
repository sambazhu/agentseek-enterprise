# P1 生命周期与初稿协议补修本地验证

## 基线与边界

- 分支：`enterprise/v0.1.2-p1-workflow`；基线：`0c4060f53a47d58e24a05f07131a389bb2ca7b6b`。
- Linux 内容复测原报告保留；production、GA、hotfix1、M3 不变。
- 本轮只修改本地代码、测试和文档；未操作 Linux 网关、配置、数据库或生产 MCP。
- 模板仅同步本轮 Python 差异，未覆盖参考工程或其他既有定制。

## 行为变化

| 项目 | 当前行为 |
| --- | --- |
| 创建名额 | published / delivered 均不再占用同一租户、请求人、数字员工、playbook 的活动名额；仍最多一个活动任务 |
| 数据迁移 | 新增 revision 12，重建活动任务部分唯一索引；不改历史行、不重写旧迁移 |
| 发布后内容 | 新建、修订、首次确认内容合同，以及新增 Source / Evidence / Claim 均拒绝；相同历史写入的幂等返回保留 |
| 历史交付 | 发布和交付记录保留；按任务编号读取本人历史，仍执行原版本、审批、内容摘要、本人下载授权校验 |
| 取消 | published / delivered 不可取消；提示直接新建，不修改既有状态机转移 |
| 当前任务 | 优先选择活动任务；没有活动任务时回显最近已发布或已交付任务 |
| 初稿协议 | 模型只需提取有证据的完整原句，可以省略章节或返回空 claims；程序补齐全部章节和固定待确认声明 |
| 无证据初稿 | 无章节绑定 Evidence 时不调用初稿生成模型；输出仍走原请求授权与提纲门禁 |
| 类型豁免 | 模型生成的 risk / recommendation 不作为自由文本入稿，改由程序固定声明；fact / inference 不降级、不修复证据绑定 |
| 中文 UX | 待确认问题显示研究问题正文，不显示内部 question_id；拒绝提示包含本轮失败背景与下一步 |
