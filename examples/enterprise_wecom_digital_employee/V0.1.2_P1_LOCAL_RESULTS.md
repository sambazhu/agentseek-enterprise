## 本地变更

| 范围 | 实现 | 边界 |
| --- | --- | --- |
| 路由 | 显式动作/服务优先；活动任务增加上下文续接；独立身份/OA 等问句走 Direct Turn；多服务澄清提供候选 | 不是新增 LLM 分类器；路由不授予写入权限 |
| 取消 | 新增工具与确定性消息入口；委派人范围校验；保留历史 | 不清理生产遗留任务；问句、否定和转述不取消 |
| DeepSeek | 初稿结构化生成显式使用 function_calling；继续校验 DraftClaimBatch | 无非结构化正文降级；真实 API 尚未验收 |
| 报告交互 | 确认需求并授权后可连续执行内部研究、提纲、可审阅初稿；缺口时返回可执行选项 | 外部搜索、初稿接受、审批、渲染、发布、交付各自保留授权 |
| 身份介绍 | WORK 关闭仍可确定性回答岗位/能力/用法；人类员工身份与数字员工岗位分开 | 不展示 OA 账号；不将已配置等同于已连通 |
| MCP | OA 本人只读查询、远端参数描述、制度/外规固定集合业务工具 | 新开关默认关闭；复杂 schema 和报销流程归属未验证时拒绝 |
| 身份注入 | graph state 显式携带所需账号；与 runtime user_key 核对；ToolRuntime 从模型工具参数中排除 | 非当前员工身份及群聊个人查询在连接前拒绝 |
| 提示词与模板 | 简化阶段说明；汇总缺失字段；同步 P1 模板改动及 pack 摘要 | 未覆盖用户部署的静态欢迎语；未复制同事工程的环境配置或日志 |

## 已覆盖的新增边界

| 测试对象 | 证据 |
| --- | --- |
| 真实 ChatOpenAI 请求序列化 | HTTP Mock 验证不发送 json_schema response_format；工具返回非法结构时拒绝；不访问真实端点 |
| LangGraph 身份通路 | 实际 StateGraph / ToolNode 测试确认状态未被丢弃、运行时身份正确注入 |
| OA 权限 | 缺失身份、群聊、他人账号、状态账号与 user_key 不一致均拒绝；拒绝请求零远端连接 |

| 自动初稿 | 组合确认、已有 Brief 自动推进、版本伪造、缺口暂停、重复请求及授权边界 |
| 旧报告流程 | 既有逐版本确认、审批、渲染、发布、下载测试保持通过 |

## 过程中发现并修正

| 发现 | 处理 |
| --- | --- |
| 可空 ToolRuntime 联合注解导致工具 JSON schema 生成失败 | 改为框架可识别的注入类型，并增加工具 schema 测试 |
| 账号不在 runtime.context，且 graph 未声明员工状态字段 | 按实际框架结构贯通 graph state，并与脱敏身份键核验 |
| 提示词修改后 pack 摘要断言失败 | 提升版本、同步摘要及引用，再通过完整测试；未绕过摘要验证 |
| 模板基线存在 P0 历史差异 | 仅同步 P1；settings 的 SecretStr 等历史差异、旧消息 ID 提取差异未纳入本次改动，不宣称模板全量等价 |
