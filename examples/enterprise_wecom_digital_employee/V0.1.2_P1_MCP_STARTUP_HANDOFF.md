# MCP 标准启动接线收尾复验

## 范围与前置

本次是 `8d0ee49` 三层配置补丁的收尾，沿用 P1 分支；候选完整 SHA 以交付回传为准。
仅修改生效 JSON 缩进、标准脚本路径接线及测试文档。无 SDK 安装/升级、依赖或锁文件变更。
外部 `agent_skill_mcp` SDK 继续由现有 venv 提供；脚本不会自动下载或解包 wheel。
Linux 三层验证通过来自用户回执，非 Codex 现场复验。WORK 研究与 null/损坏 local 活体
仍为 NOT_RUN。旧 47 篇语料已按用户授权清理，本文不授权任何进一步数据清理。

## 1. 受控启动复验

1. 核验候选与 `8d0ee49` 祖先关系及两远端一致，备份启动环境、服务单元与临时 `.pth`。
   当前 production 仍 `0af15af`；本次不授权合并 production 或移动标签。
2. 使用候选树 `scripts/run_gateway.sh`，不手填 skill-mcp 路径。
   脚本将同树 example/src、contrib/agentseek-skill-mcp/src 置于继承 PYTHONPATH 之前。
   不清空其他仍需的 contrib 路径；当前 overlay 的其他包仍须同版本配套。
3. 受控停机后，检查临时 `agentseek_skill_mcp.pth` 的准确位置与内容。
   只对本次 Linux 创建的该文件做可恢复移出；若包含其他用途路径，先拆分确认，禁止整类删除 `.pth`。
   这一步不是删除 SDK：保留 venv 内原有 `agent_skill_mcp`。
4. 配置明确的 `AGENTSEEK_ENV_FILE`、`AGENTSEEK_GATEWAY_LOG` 和 `SKILL_DOCS_DIR`。
   Linux 日志路径由现有部署值显式指定；本补丁不改变脚本既有 macOS 风格默认日志路径。
   检查 .env/服务环境没有再次覆盖 PYTHONPATH 为旧树；不打印环境全集或真实配置正文。
5. 启动唯一网关并核对进程内来源：agent、merge、loader 均候选树，SDK 为现有 venv。
   确认未依赖被移出的临时 `.pth`。`python -S` 本地测试只验证包定位，不代表 SDK 依赖可在 -S 下运行。
6. 发送首条消息，确认进程内实际平台同步成功后合并为预期 7 服务；
   文件存在或内容正确不能替代本进程同步证据。
7. 核对生效 JSON 为两空格缩进、0600，且结构与原三层合并结果一致。
   OA 本人、IT、HR、tavily 确认门冒烟；WORK 保持 false，不追加研究任务。
8. 回传完整 SHA、脚本和模块路径、同步/合并计数、四项冒烟、双健康、单实例、错误增量、
   临时 `.pth` 处置及 NOT_RUN。任何 SDK 导入失败先停止，不临时联网升级。

## 2. 后续正式发布（另待批准）

1. 启动复验通过后申请 production 快进与去 overlay 授权，不凭本工单自行发布。
2. 获批后先备份三配置、.env、服务单元和 itdept 定制；安全处理 tracked mcp.json 的
   skip-worktree 与 `.git/info/exclude` 过渡项，解除标记前保证本地私有副本已备份。
3. 使用普通快进，恢复生产树定制；将脚本、全部 contrib 解析、SKILL_DOCS_DIR 切到生产树。
   明确去除旧候选树 PYTHONPATH/服务 Environment 引用和临时 `.pth` 残留。
   只核对路径与计数，不提交运行配置；三文件应 ignored 且不再 tracked。
4. 重启后复验真实同步、七服务、四项冒烟与单实例双健康，再报告发布结论。

## 3. 回退

1. 收尾复验失败时，停网关，恢复已记录的 `8d0ee49` overlay 启动环境与临时 `.pth` 备份；
   三层配置保持其已验证布局。此回退仍是 overlay，不冒称纯生产路径。
2. 若需回到 `0af15af`，同时恢复旧代码、旧混合配置、旧 .env、定制与标准运行命令；
   依据备份逐项移除候选树路径、SKILL_DOCS_DIR 和临时 `.pth` 的残留，确认实际加载路径。
   该版本可能仍存在此前 skill-mcp 不可导入问题，必须披露，不能把缓存状态当作同步成功。
3. 不回退数据库，不恢复已授权删除的语料，不 force，不动标签；恢复后核验单实例和双健康。
