# 平台知识库 MCP 合同只读核验（0d83500 前置，Linux CC，2026-09-14）

## 0. 判定

**研究管道合同不满足——停在线上研究入口**（按交接单 §MCP-3）。三项硬缺口：
检索无 search_mode、**无独立 chunk 回读工具**、**服务端无知识域隔离（跨 kbCode
越权实测成功）**；另有战略库平台侧索引缺失（全部查询失败）。F4b 仅可本地
固定 Evidence 验证，不计平台端到端。

## 2. 脱敏返回样例（IT 制度库真实查询，结构巡检）

```
data: list[hit]  每-hit：
  sys_data_id      uuid36（chunk 级标识）
  file_code        32hex（文档级标识）
  chunk_content    正文（截断展示）
  score            0.5766（单一融合分）
  sys_source_ids   JSON 串（kb_submodel/source 元数据，len≈300）
  chunk_bboxs      页面坐标（len≈1113，版面级）
  show_content / chunk_representation（展示/表征副本）
  chunk_sort_number 9（块序号）  start_page 8
```

## 3. 分数语义

单一**融合分**（fusionType=lws：topN=5/topKVec=10/topKText=10/keywordWeight=0.5
等融合参数在 schema 暴露）；**无 keyword/semantic 分腿**——研究管道的
minimum_keyword_score/minimum_semantic_score 双腿分数门无对应物。

## 4. 稳定回读

- **无 knowledge_read_chunks 等价工具**：内容随检索内联返回（chunk_content+邻块
  chunkConfig），无按稳定 ID 独立回读路径；
- 稳定性实证：同查询两次命中签名（file_code/sys_data_id/chunk_sort_number/score）
  **逐字节一致** ✓——标识稳定，但仅"再查询"可得，非"按 ID 回读"。

## 5. 授权范围（缺口实证）

- **kbCode 客户端可控且服务端不校验**：战略库端点传 IT 库 kbCode=e3n5qeo1ec2w
  → **成功返回 IT 库数据**（file_code f2b9f756…=IT 制度文档）——知识域隔离仅靠
  调用方约定，任何端点可达任意库；
- 无员工/租户维度参数（OA 库的 oa_account 注入体系不适用于 KB 端点）。

## 6. 战略库可用性

战略发展部知识库（研究管道目标库）全部查询失败：`KortexQueryException:
kbIndexCode不存在, kbCode: urzi680on449, kbIndexEngineType: builtin_vector`
（显式传 kbCode 亦然）——**平台侧索引缺失**。IT 制度库/HR 库正常。
