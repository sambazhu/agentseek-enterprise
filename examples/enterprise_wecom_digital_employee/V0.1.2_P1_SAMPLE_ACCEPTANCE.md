# v0.1.2 P1 样例模板验收结论与使用限制

## 当前裁定

| 项目 | 结论 |
| --- | --- |
| 用途 | 行业报告工作流的样例模板，供开发者参考；当前没有具体业务交付需求 |
| 用户决定 | 跳过人工业务审核；不再作为本轮样例验收或发布前置 |
| 工程验收 | 已实测范围内通过；本轮生成质量攻坚收口，不代表所有路径或业务质量通过 |
| 人工业务审核 | 按用户决定跳过，非 PASS；不要求补交业务评审表 |
| 内容完整性 | 未验证、不结案；转为样例适用限制，不阻塞限定用途的样例验收 |
| 审批能力 | 模板人工审批能力保留；本决定不批准任何初稿，不改变 Claim 状态 |
| 发布状态 | 待单独确认；本文件不授权 production 合并、部署、标签或开关启用 |
| 依据 | 用户本轮定位调整及 Linux 回执；报告提交 ab97bbe，实测代码 ab4698c，schema 12 |
| 核验边界 | 本轮核对仓库报告，未再次调用模型、连接 Linux 或查询生产数据库 |

## 本轮机制证据

| 项目 | 已取得证据 | 不作外推 |
| --- | --- | --- |
| 选择式生成 | 模型仅选择 sentence_id/section_id；一次调用保存 6 条 fact 与 2 条程序占位 | 单次成功不是稳定成功率或任意语料保证 |
| 原句绑定 | 程序组装源句并通过账本校验 | 引用匹配不是事实真实性认证；不保证保留原始排版字节 |
| 用途分层 | 6 条 fact 中包含 2 条 background 用途；背景不关闭对应缺口 | fact 是 Claim 类型，不等于已核实事实；不得将背景扩写为行业结论 |
| 缺口保留 | topic/digital/priorities 未解决；相关章节保留占位 | 零候选可能来自语料、检索或准入限制，不能仅归因为资料不存在 |
| 幂等 | 已生成初稿的重放为零生成调用 | 不等于所有消息路径都执行了本轮复测 |
| 失败处理 | 选择修复、二次失败及零部分保存有离线覆盖 | 对应活体路径 NOT RUN；不以离线通过替代活体通过 |
| 本地回归 | 交接单记录 641 passed / 1 skipped | 历史验证结果，本次 docs-only 未重跑该套测试 |

## 样例使用限制

| 范围 | 限制 |
| --- | --- |
| 业务使用 | 不保证覆盖完整、结论准确或可直接用于业务决策；转为真实业务应用时由采用方另定审核标准 |
| 证据状态 | Claims 保持 unverified；不自动确认 Draft、审批或发布报告 |
| 研究资料 | 研究接口与外采平台 KB 不可直接等同；平台 MCP 冒烟成功不证明报告研究合同兼容 |
| 模型 | 已验证端点组合不代表全部兼容端点均可使用；供应商切换需验证结构化输出 |
| 交付 | signed_link 正例未验证，不宣称已有实际下载能力 |
| 其他范围 | 既有 NOT RUN、平台 MCP 问题及用户暂缓项继续留档，不因样例收口转为已解决 |
