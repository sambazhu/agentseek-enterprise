# 离线复验业务材料统一生成器

## 范围

本轮承接 a5bac60 的如实披露：W10–W13没有可复现生成器。
新增模板图编译器、假数据样例与落盘自检；不修改历史脚本或冒称已接入现场。
先完成合成复验，再审阅现场输入；不启动有效期，不创建、不部署、不清旧状态。

## .171 备料

1. 核对本工单提交，普通同步双远端。保留原归档，不动production/标签。
2. 新包仅交付三个 scripts 文件、本工单与 MATERIALS_REFERENCE、SHA256清单。
   工具未加入运行时wheel，不需要构建新wheel，不改变45模块/2运行入口。
3. 测试复用已批准50adc3f的独立业务venv和原有pytest；不得与R1混装或联网补包。
4. 交接新目录给.172，检查全部payload摘要。输入是合成假数据，不含现场配置/凭据。

## .172 合成复验

1. 核对到货摘要。仅使用本轮工具，不运行历史generators/脚本。
2. 在新scratch使用 business_materials_example 的 --directory 生成禁用合成输入。
   读取其输出的input路径与摘要，传给 business_materials 的 --input/--sha256。
3. 成功应为 MATERIALS_READBACK_VERIFIED、files=16、execution_authorized=false。
   对同一输入运行 --verify-only；应只读成功，文件内容/mtime不变。
4. 在已安装业务wheel的独立venv下运行本轮 test_business_materials.py；
   使用 python -I -m pytest，-o pythonpath 指向本轮工具目录。预期39 passed。
   不运行仅适用于完整仓库的清单工具测试，不拼异源闭包。
5. 合成破坏测试已经覆盖漏key/错摘要/权限/引用/漏写/篡改；可依据测试报告核验，
   不删除真实物化文件、不篡改真实配置来“实证”。
6. 回传新目录的脱敏报告+清单。判定上限 BUSINESS_MATERIALS_OFFLINE_PASS。
   .171只读拉取归档；不拉真实输入/输出正文，不把任何私密目录入Git。

## 后续现场输入准备（不在本轮执行范围）

1. 安装方准备受控源交接清单、监督身份清单、完整模板图与已批准路径。
   源密钥/证书已有就复用受控源，不因生成器自动签发、改写或轮换。
2. 核对真实W0确认、候选/输入/请求绑定、批准值、目录使用依据。
   不让工具“补造”缺失确认或决定何时批准。预备禁用输入也须注明其事实范围。
3. 独立审阅输入并钉完整摘要。输出目录必须新建，运行目录不由生成器初始化/重置。
4. 获批后生成；缺预期摘要、源不存在或读回失败时保持BLOCKED。
   不以重新计算待验输出摘要、“只修一个文件”、改目录重试替代复核。
5. 激活前再次 --verify-only；按返回的service_sha256程序化核对unit启动参数。
   网关grants、真实TLS、运行身份、有效期和许可额度继续走现有批准与现场门禁。
   此自检不替代这些检查，不将材料成功记成服务READY。

## 失败保留与恢复

工具不启动服务，无服务回退动作。失败输出保留作证，不覆盖、不自动删除。
现场旧材料、额度、fence、账本和manifest不在工具写入范围。
部分输出即使含approved=true也不代表成功或可激活；必须通过全量读回与独立执行批准。
