## 真实输入准备与禁用生成

1. 按INPUT_MAPPING填parameters.json。来自.171的request/owner/input_ref/问题全文及摘要只读受控交接，
   .172不另铸request_id；源资产摘要来自独立交接清单，pins来自既有只读取证。
2. 缺少W0/确认、源摘要或审批范围内目录时，列缺项停止；不猜测、不自动开始窗口、不创建目录替代旧状态。
3. 安装方审阅parameters并钉摘要。以下仅是模板，变量由现场受控填写；无凭据正文进命令行。
   本地已测试同款命令的合成路径，真实命令未在开发端执行。

```bash title="not executed in this run"
"$BUSINESS_PYTHON" -I "$TOOLS_DIR/business_materials_input.py" \
  --parameters "$PARAMETERS_FILE" --sha256 "$APPROVED_PARAMETERS_SHA256" \
  --output-input "$NEW_INPUT_FILE" --generate
```

4. 成功后读取返回input_sha256，传给只读复验；不要把参数摘要错当input摘要。

```bash title="not executed in this run"

  --input "$NEW_INPUT_FILE" --sha256 "$GENERATED_INPUT_SHA256" --verify-only
```
