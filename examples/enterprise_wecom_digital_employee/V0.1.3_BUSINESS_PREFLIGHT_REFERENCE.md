# 本端业务准备预检输入合同

## 范围

工具：scripts/business_preflight.py。入口参数：--input（私有JSON路径）、--sha256（审阅后独立钉住的完整摘要）。
解释器：已装业务wheel且支持sqlite3.Connection.deserialize的Python3.13隔离解释器。
依赖：同目录本候选business_materials.py。零平台访问、零服务操作、零数据库构造/迁移。

| 根字段 | 精确含义 |
| --- | --- |
| schema | 整数1 |
| role | node或gateway |
| owner_id | 已审真实绑定，非模型猜测；1..1024字符 |
| request_id | 已审本轮完整64位小写hex；不能复用历史request |
| store_file | 本端实际BusinessStore的business.sqlite绝对规范路径，不接受不存在或空白占位数据库 |
| materials_input | 仅node必需；统一生成器编译输入，不是parameters或service.json |
| materials_sha256 | 仅node必需；已审编译输入的完整预期摘要 |
| manifest_file | 仅node必需；必须等于材料supervisor目录下manifest.json |

node精确8字段，gateway精确5字段，不接受其他字段。输入及父目录0600/0700、当前执行身份所有、无链接。
输入摘要必须经审阅钉住，不能把任意现场文件现算摘要当批准。

## 输出与检查面

| 输出/检查 | 含义 |
| --- | --- |
| LOCAL_PREPARATION_PASS | 本端当前静态准备检查通过，不是双端或真实平台PASS |
| execution_authorized=false | 永不产生创建/切换/恢复/清理权限 |
| live_gate_required=true | 临近执行仍须真实身份/心跳/无告警/平台空闲/有效期/预算/批准链核验 |
| binding_sha256 | 对encode([owner_id,request_id])的SHA256，供双端比对；报告不输出原值 |
| preflight_sha256 | 输入钉值；不是现场状态永久凭证 |
| terminal_rows | 本端已保留的终态数量，不输出SQL行内容 |
| BLOCKED、exit 2 | 检查失败或证据不足；不修复、不清目录、不闭合attempt |

两端均检查：数据库完整性、全部行只能为succeeded/failed、本轮request未在任一历史行出现、
目标attempt未存在、owner一致。未知状态、reserved、reconciling均阻塞。
node另检查：统一生成器verify-only全部16件读回；实际源权限及独立预期摘要；跨文件引用；
request/store路径与service绑定；tracking/lifecycle/quota/fence均0700且为空；manifest0600、
run/template匹配且sandboxes={}。不调用register_run，不创建manifest锁文件。

## 只读数据库限制

数据库通过受控文件读取到内存后检查，不连接现场SQLite文件，不写事务或checkpoint。
只接受delete-journal格式；存在-wal/-shm/-journal任一sidecar即阻塞，不忽略未checkpoint数据。
数据库上限2MB、attempt上限10000，超限明确阻塞；不得删历史来满足上限。
检查后重读文件比对内容并再次检查sidecar。无法证明之后状态不变，成功不替代执行时门禁。
缺数据库、权限错误、格式/表异常均阻塞，不自动初始化。

## 未覆盖面

gateway仅核对本端store，不声称已核对grants、模型、网关进程env或导入路径。
node不声称已核对现役unit启动摘要、实时pins、boot_id、心跳、guest=0或有效期。
这些既有现场核验继续单列；两端binding_sha256一致也不代替grants/permits全字段核对。
脚本不处理failed/reconciling恢复、不新铸request、不接受“强制通过”选项。
