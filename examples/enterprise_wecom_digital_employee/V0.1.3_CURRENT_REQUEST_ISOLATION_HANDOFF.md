# 复验当前请求隔离

用于 W18 收口后的网关候选离线复验。基线为 `935f396`。
本交付不授权服务切换、平台探测、创建、发送、状态清理或额度复用。
W18 的工具调用不可复原，不将本次静态发现冒充 W18 唯一根因。

## 1. 核对变化面

- 网关结果查询先读取可信、scope 匹配且有效的 server grant，再按 owner/request 精确查找。
- 没有对应 attempt 返回 `not_executed`；不读取、恢复或回写 owner 最新历史任务。
- 已有 attempt 还需匹配 input_ref 和 instruction 摘要，冲突即拒绝。
- 返回 request_id、attempt、matches_current_request；CSV 读取仅接受当前成功 attempt 的 artifact。
- 历史文件仍通过既有 workspace listing / 显式原生投递访问；不作为当前执行证明。
- 诊断专用 spec 保留历史只读查询，结果标记 historical、matches_current_request=false；不新增执行工具。
- 不修改执行组件、wheel、数据库结构、材料字段、授权合同或节点服务。

## 2. 核对输出边界

正式 `sandbox_spec.build_spec` 包装最终响应，按入站原始问题与可信 grant 的 instruction 摘要精确匹配。
匹配的执行问题使用本轮账本状态生成确定性回复，不透传模型的成功声明。
成功时复读当前 artifact，呈现持久化 CSV；未执行、失败、未决或证据不可读均不声明成功。
调用与流式入口均经过该边界；匹配执行问题不走 direct_response 快捷回复。

工作区回写和企微文件发送独立验收：确定性执行回复不将持久化等同回写，更不等同投递。
普通问题和明确索取历史文件保留既有路径。
本守卫只覆盖精确匹配可信当前授权的问题，不是任意自然语言幻觉过滤器；无有效 grant 时不得宣称全局拦截。
它不强迫模型调用 run、不补发、不重试。模型未调用时如实回复本轮未执行。

## 3. 核对脱敏观测

三项沙箱工具入口输出 `sandbox_tool` 结构化 INFO 行：

- 开始：固定工具名、服务端随机 event、调用标识 SHA256（缺失记 absent）。
- 结束：同 event、固定状态白名单、current 布尔、request_id 的 SHA256。
- 异常/取消：同 event 与 failed/cancelled；不记录异常正文。

不记录工具参数、CSV、结果正文、路径、身份明文、凭据、下载链接或投递句柄。
此日志独立于 Langfuse；不修复或调用现场 Langfuse 接口。
schema 校验前拒绝、未形成有效调用的模型输出、进程硬杀可能没有完整工具事件；不得称全覆盖。
线程取消仍沿原语义：取消等待不证明后台线程停止，不允许据此重创。

## 5. 回传并停止

回传新目录：脱敏报告、实测命令、测试结果、源码清单及完整 SHA256。
判定上限 `CURRENT_REQUEST_ISOLATION_OFFLINE_PASS`。
业务 wheel 与 `935f396` 相同，不重装节点、不打新 wheel、不清 W18 历史。
现场采用另审：spec 必须为业务入口，实际工具装配与新增守卫模块导入均须核验；仅配置存在不算。
采用需一次另批网关切换；若涉及回退，重新检查 NFD inflight/uncertain 与 outbox 回退硬门。
下一次真实验收使用新批准材料；W18 未耗额度不自动沿用。
