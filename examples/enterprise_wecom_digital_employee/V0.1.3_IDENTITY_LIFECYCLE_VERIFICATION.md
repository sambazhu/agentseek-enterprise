## 每轮状态与身份缓存

| 对象 | 行为 / 边界 |
| --- | --- |
| Bub 本轮 state | 已安装框架 BubFramework.process_inbound 每轮新建字典，再合并 load_state 返回；测试实际运行此方法，不用手工旧 state.update 模拟框架 |
| 用户记忆 | EnterprisePlugin 从独立短期存储加载；新建运行字典不删除记忆、文件、账本或历史 |
| 员工身份 | 每轮插件处理身份；AGENTSEEK_ENTERPRISE_IDENTITY_CACHE_ENABLED 默认 false，因此默认每次有效身份请求调用提供方 |
| 员工身份缓存 | 开启时按 provider+account 缓存成功结果；TTL 默认 600 秒，容量默认 1024；到期重新查询；未找到不缓存为成功 |
| 撤销时效 | 缓存有效期间可继续命中旧员工资料；到期查无身份才不提供 runtime 身份。未实现主动撤销广播，不能声称立即失效 |
| 企微 ID 转换 | open_userid→userid 是另一层缓存；不能用该缓存的启用情况推断员工资料缓存是否启用 |
| 现场配置 | 本轮未读取 .171 环境；不知道现场员工资料缓存是否开启，不推断生产查库频率 |
| 状态不是授权 | 同用户 current_files 缓存仍可存在，但没有可信 runtime 身份时原生文件工具拒绝；本轮不宣称所有历史正文被擦除 |

## 模拟边界与未完成项

| 面 | 如实边界 |
| --- | --- |
| 身份提供方 | 合成目录及合成 open_userid 映射，不是生产员工数据库 |
| 长连接 | 从已解码回调载荷开始；响应发送与排队调度替身，分发处理真实；未测 TLS、订阅、断线重连或真实消息投递 |
| checkpoint | InMemorySaver 在同进程图重建中保留；不是磁盘 checkpoint 或 OS 重启；当前 agent.build_agent 未显式传入 checkpointer，不可假设现场存在此恢复路径 |
| 消息历史 | 无身份时历史消息仍可能保留；测试保证工具权限不来自旧句柄，不能宣称历史内容完全不可见 |
| 缓存故障 | 缓存关闭和过期后的失败拒绝已测；缓存命中期间不主动查后端是既有语义，不包装成修复 |
| I01/I04 | 新增框架实际合并、失败恢复、长连接分发、图 checkpoint 证据；完整网关跨进程恢复与长期 StoreBackend 仍待验证 |
| I05–I07 | 同日同内容关联、双用户日志关联、双端差异及竞争授权仍未在本轮闭合 |
