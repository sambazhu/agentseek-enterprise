## 范围与实证

| 项 | 合同 |
| --- | --- |
| 基线 | 4da5b60，446 项全套 |
| 判定上限 | IDENTITY_TIMEOUT_OFFLINE_PASS；不代表真实连接或生产重启隔离通过 |

| 恢复 | 仅下一条新消息重新解析成功后恢复权限，不自动重放原请求 |
| 线程限制 | 超时取消等待，不终止同步线程；测试显式释放阻塞线程，不宣称底层网络已停止 |
| 缓存限制 | 本专项关闭员工身份缓存；不声称立即撤销仍在有效期内的缓存，也未覆盖 resolver 内部缓存副作用 |
