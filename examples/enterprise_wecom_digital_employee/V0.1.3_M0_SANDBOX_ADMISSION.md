# v0.1.3 M0 CubeSandbox 准入与验证清单

状态：PARTIAL。Linux CC 于 2026-09-06 完成只读准入预检；PoC 尚未执行。

## 已确认的架构合同

| 项目 | 决定 |
| --- | --- |
| 生产后端 | 仅 CubeSandbox；失败不回退宿主 Shell |
| 集成方式 | 独立 Execution Broker + Cube 原生 SDK |
| 触发时机 | 受授权能力首次需要执行环境时懒启动 |
| DirectTurn | task_id + execution_id + attempt |
| Playbook | 同上，额外关联 work_id + phase |
| 复用 | 一个执行单元可跨多个连续命令，跨 attempt 新建 |
| 释放 | 输出与检查点提交后；用户/审批等待不长期占 VM |
| 输入 | 按授权 manifest 固定版本，只读导入 |
| 持久化 | 私有 Content Store + ledger，最后成功提交的 revision 是恢复点 |
| 输出 | ExecutionOutput 与正式 Work Artifact 分开 |
| 快照 | 首版不启用 VM 快照自动恢复 |
