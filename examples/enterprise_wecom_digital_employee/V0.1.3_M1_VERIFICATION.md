# v0.1.3 M1 离线合同复验

## 前置

- 使用独立检出的 M1 功能分支，不切换生产网关工作目录。
- 从仓库根运行；仅使用合成数据，不加载 .env。
- 准备 uv 和 Python 3.10/3.13。解释器及工具首次下载需要网络；测试自身无需网络。
- 不安装 Cube SDK，不操作 .172，不改 M0 运维件，不访问共享数据库。

## 执行

1. 执行两套解释器测试。pytest 临时目录承载 SQLite，现网文件不在范围。

   ```bash
   uv run --no-project --python 3.10 --with pytest==8.4.2 pytest -q contrib/agentseek-execution/tests
   ```

   ```bash
   uv run --no-project --python 3.13 --with pytest==8.4.2 pytest -q contrib/agentseek-execution/tests
   ```

2. 检查静态门禁。Ruff 必须显式 no-fix，避免修改工作区。

   ```bash
   uv tool run ruff check --no-fix --target-version py310 contrib/agentseek-execution
   ```

   ```bash
   uv tool run ruff format --check contrib/agentseek-execution
   ```

   ```bash
   uv tool run ty check contrib/agentseek-execution/src --python-version 3.10
   ```

3. 核验补丁空白与工作区。不要将临时测试文件加入版本控制。

   ```bash
   git diff --check
   ```
