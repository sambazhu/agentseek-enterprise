# M3 R1 生成器版本安装与阶段二审批清单准备

本轮用户仅批准：安装固定候选、重验并登记后续显式入口、准备脱敏审批清单。
不批准真实平台调用、创建、探针、结束查询、凭据物化、现场 true 预批或 W0 放行。
5 秒余量仍是待裁定建议；本轮批准不使其生效。

- 固定代码：`5d3c27bf1d5d15e0ad09f0ff1fcd6e3e8a70cfdc`。
- wheel SHA256：`188a0d2cdcd9705befe916a9b850e8791b81471ca88d455a8c97d9b94df9fceb`。
- 已验报告：`eb5349325bab18a40f738a3b43cf7b6e0626d0ad`，Linux 799/5、35/8。
- 现用 be59e54 显式入口及 aa9e1e5 常驻监督安装全部保留。

## 2. .171 备料与交接

1. 核验双远端与候选链。复用上一轮已验包，重新逐文件检查摘要。
2. 经既有批准通道交付工单和所需材料；不修改候选、不把现场凭据入包。
3. 不向 .172 安装/配置目录写入，不代为重启或执行；回报到货后等待用户通知。

## 3. .172 安装并登记入口

1. 只读核对现有安装与监督引用；不要读取凭据或请求控制面。
2. 新建 `/opt/agentseek-m3-releases/5d3c27b/venv`，使用已批准解释器和离线固定依赖。
   目标已存在且来源不明则停止，不覆盖。保持版本目录私有，不安装到系统或生产 venv。
3. 用新 venv 的 python -I 运行候选安装检查：35 模块来源/摘要一致，8 无效入口拒绝。
   运行 m3_materialize、m3_slot、m3_lifecycle 的 help；不得给有效现场配置。
4. 写本版本私有 INSTALL-RECORD，记录候选、wheel、入口、模块来源、检查结果及回退路径。
   后续显式入口登记为 `/opt/agentseek-m3-releases/5d3c27b/venv/bin/python`。
   保留 venv 路径用于启动；即使其解释器符号链接解析到共享 Python，也不能改用共享
   Python 路径直接启动，否则可能丢失 venv 的安装上下文。
5. 不创建 current 软链、不改 .pth/PATH/PYTHONPATH/unit/监督 pins，不启动任何任务。
   核验常驻监督和已有入口文件未变。登记仅改变后续工单选用的版本，不表示进程换版。
6. 安装/核验失败，不登记新入口。回退只恢复后续入口选择至 be59e54；新目录保留审计，
   不停监督、不删除或覆盖旧安装。

## 4. 准备脱敏审批清单，不生成可执行批准

另建本轮说明文档，逐项列“已知事实 / 建议 / 待用户批准 / 动态待填”，禁止代填确认：

1. 候选与入口：本轮安装摘要和登记路径；production/标签不涉及。
2. run/template：现已登记 run_id `agentseek-m3-r1-20260917`、template_id
   `tpl-c4ba4bf8e2fb4668b0b7f22c`。不新建 run、不重置额度或栅栏；当前有效性在真实窗口另验。
3. W0：责任人、所有已知创建入口及 writer、逐人禁创确认、拟议窗口起止（明确时区）。
   未获得确认的 abstain 保持待定，不写 true，不推断“无人回应=同意”。
4. A/B 创建批准与逐行委托：分别列固定计划、矩阵、有效期、候选和输出目录，
   标明仍需用户逐项批准及批准后钉摘要；A 五请求，B 六请求含 X1，120 秒不延长。
5. 预算：5 秒为建议而非生效值；对应 A 首行需剩余85秒、B需101秒。
   真平台各段仍未测，预算不足可导致整槽 NOT RUN；不缩减矩阵、不自动重试或创建替代 guest。
6. 凭据：仅记录“受控来源已登记/物化待批”和目标路径，不复制、输出、读取或物化 key。
7. 顺序：A 的用户批准、预批审阅与摘要固定在 A 创建前完成；A 结束后才准备 B 的
   动态后继材料，并在 B 创建前完成 B 的批准与预批固定。创建后的机械生成无人工新增授权。
8. 动态字段：A/B 密封回执、实际 sandbox/intent、A 成功记录和相应摘要均标待真实事实产生；
   不用合成值冒充，不预造回执。未知 W0 身份、窗口与有效期列为用户问题。
9. 失败纪律：UNKNOWN/身份或审批异常/阳性失败即停，保留 intent/fence/quota；
   不恢复执行、不手工抽取部分生成审批、不删除记录重跑。
10. 验证边界：离线通过、生成器合成计时与真实全链分别记录；M3_READY 尚未达成。

只写脱敏说明清单；不调用 materialize，不修改既有禁用草稿，不写现场
approved=true/materialize_exact_rows=true/w0_accepted=true 文件。
清单不包含预批或安装正文（control 含 api_key），也不包含密钥内容或敏感输出。
