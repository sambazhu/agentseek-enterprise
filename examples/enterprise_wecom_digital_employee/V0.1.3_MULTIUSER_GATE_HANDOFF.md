## 语义矩阵

| 场景 | 实测行为 | 不得扩大的结论 |
| --- | --- | --- |
| 网关存在其他 owner 的 reserved/reconciling | 本地 reserve 拒绝；当前请求无新增行、无 exchange、无 provider.create | 门禁是全库串行，不是每用户并发容量 |
| 仅节点存在其他 owner 的未决行 | 网关 advisory 可为 true；本地先占位，远端 reserve 拒绝；网关进入 reconciling | 不可称“竞争失败方均未消耗请求” |
| 节点返回 not_found | 只读恢复失败，网关保留 reconciling；不重新 execute | not_found 不是未发送或可安全重试证明 |
| 其他 owner 的 failed/succeeded | 释放全库未决门禁，允许不同合法请求；原 request 仍不能再次 reserve | 终态不重置旧 request，不铸新授权 |
| advisory 后新增未决行 | 随后的原子 reserve 拒绝 | grant_unused 不是锁，也不是现场最终授权 |
| 节点成功、网关丢响应 | 网关暂阻其他 owner；只读 recover 对账后释放未决门禁 | 不删除行、不自动重创、不把镜像暂态当节点失败 |
| 八个独立连接竞争同一 SQLite | 未决赢家保留期间仅一次占位成功 | 不是跨数据库分布式锁、跨机容量或真实 quota 验收 |
| 两个有效 permit 竞争 | 首请求在合成 create 内保持在途；第二请求 reserve 被拒，无节点 attempt；首请求完成后重复读取不再 create | 并非真实双 guest 并发；未测试公平性、压力容量或竞争方自动重试 |
