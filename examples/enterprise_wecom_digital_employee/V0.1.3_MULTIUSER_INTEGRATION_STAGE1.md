## 已执行用例（10 项）

文件：`tests/test_sandbox_multiuser_integration.py`。

| 场景 | 参数数 | 断言 |
| --- | --- | --- |
| 通道 → 插件 → 真 ToolRuntime | 2（app/callback） | 两用户同时分发；正文假冒身份及 context 中旧身份被可信 sender 覆盖；各工具只能列本 scope 文件；零发送 |
| 通道 → 工具 → outbox → HTTP mock | 2（app/callback） | 两用户各重复调用一次；仅两次上传和两次发送；素材内容逐一匹配 touser；两行 delivered；外来 ref 与外来 capability 拒绝 |
| 未解析身份 | 1 | 不签发投递 capability、不提供 runtime 身份、不列文件、零 HTTP |
| 一用户发送超时 | 1 | A 为 uncertain，重复调用无发送；B 可完成；两行 outbox，异常正文不进返回值 |
| 下一轮消息无 capability | 1 | WeComPlugin 清除旧 state 句柄；旧能力不因 state 合并沿用 |
| 记忆/文件/句柄组件重建 | 1 | 同一插件处理交错用户，短期记忆与 current_files 各自隔离；重建后记忆各自恢复、文件缓存为空、旧 capability 失效；零 HTTP |
| 正式沙箱 spec 的跨用户历史成功 | 2（invoke/stream） | 同一个 spec 并发接受 A/B；A 确定性成功、B not_executed；B 不含 A 的 attempt 或 CSV；B 无新 attempt、守卫不发起创建 |
