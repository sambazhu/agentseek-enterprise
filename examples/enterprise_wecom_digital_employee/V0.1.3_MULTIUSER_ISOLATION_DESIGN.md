## 已核实边界

| 层 | 当前实现 | 限制 / 扩展要求 |
| --- | --- | --- |
| 可信身份 | sandbox_authorization.runtime_scope 读取 runtime.context.enterprise 的 tenant/user/session 三元组；scoped_owner 对完整三元组取摘要 | 模型参数、正文中的用户标识不是权限来源；上游通道注入仍须集成验证 |
| 授权目录 | ApprovedGrantCatalog 按 scope 选唯一未过期 grant；相同 scope 两条有效 grant 拒绝 | 允许不同 scope 各有 grant，不代表允许并发创建；不按模型意愿选 grant |
| 请求解析 | SandboxRequestResolver 核 scope、期限、文件访问与 instruction 摘要 | 先拒绝外来 grant，再访问文件；不借用另一用户额度 |
| 当前结果 | request_for_grant 用 owner/request 精确查找并核 input_ref/instruction；正式守卫从账本生成匹配请求回复 | 无 grant、非匹配文本不在确定性守卫的全面覆盖内；不是通用模型内容过滤器 |
| 业务文件 | BusinessStore.read 同时限定 owner 和 artifact；artifact 由 attempt 和内容摘要派生 | 同内容不代表同一次执行；拒绝外来 artifact |
| 业务调度 | BusinessStore.reserve 在事务内检查全库未决任务 | 任一用户 reserved/reconciling 阻断共享库的新创建；首版保持此安全门，不改为每用户门禁 |
| 原生投递入口 | channel._bind_native_file_delivery 只给已解析明文身份的单聊签发私有句柄；收件人由可信地址闭包绑定 | 工具不接收 recipient；不可新增模型指定收件人或明文身份回退 |
| 投递文件 | FileDeliveryBinding.records 限 tenant/user/session/outbound，核路径、期限、大小与内容 | 文件名多义拒绝；file_ref 不能越 scope；相同短 file_id 不构成授权 |
| 投递去重 | key 包含 scope、应用/收件人摘要、file_ref、初次标志或明确重发的真实 message_id；reserve 先于读取和上传 | 各用户独立判重；uncertain 不自动恢复；api_accepted 不代表用户实收 |
| 会话命名 | ConversationAddress 单聊 session_id 为 wecom:<effective_userid>，未包含 tenant/application | 不宣称多企业或多应用共进程会话隔离已成立；需另查 harness 持久化命名空间 |
| 工作区寻址 | LocalFileStore 按 tenant/user/date/session/direction/content file_id 落位 | 同 scope、同日、同内容可能复用路径；created_at、file_ref 或 SHA 均不能单独证明新 attempt |
| 句柄容量 | 进程内 capability 最多 1024，600 秒到期，重启失效 | 容量上限不是吞吐保证；多 worker 路由、负载与公平性不在本轮覆盖 |

## 首版执行与投递合同（拟定）

| 编号 | 必须保持的规则 |
| --- | --- |
| C1 | 身份来自认证通道并进入 runtime.context；工具 schema 不增加 tenant、owner、recipient 或授权开关 |
| C2 | 用户 A/B 分别拥有 request、完整授权引用及一次创建额度；未决时拒绝另一新创建，不自动排队后执行 |
| C3 | A 的任务、文件、句柄和投递回执不得成为 B 的结果；拒绝输出不暴露 A 的明文身份、正文或路径 |
| C4 | 同 scope 同名件多义时需用户选择精确 file_ref；当前业务成功仍须 request/attempt/artifact 证据，不以“最新”代替 |
| C5 | 原生投递继续要求真实用户明确索取；任务完成不自动发送；不自动重发 uncertain |
| C6 | 备用本地计算可保留，但标注非沙箱来源与实际文件状态；不能替代本轮执行验收 |
| C7 | 多用户首轮采用不同合成内容便于诊断，同时必须保留同名同内容碰撞的负向测试；不同输入不是隔离修复 |
| C8 | 新轮材料和窗口独立批准；不复用 W19 过期配置，不改变监督或历史记录 |
