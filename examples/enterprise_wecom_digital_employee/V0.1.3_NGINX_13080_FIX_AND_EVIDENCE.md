## 三、★ 新发现：协议不匹配层（比 IP 白名单更根本）

**business_cube_session 代码使用 `http://`（plain HTTP）连接 127.0.0.1:13080**：
```python
# business_cube_session.py:228
origin = f"http://127.0.0.1:{control['proxy_port']}"  # proxy_port=13080
```

**nginx 13080 配置为 `listen 13080 ssl`（仅 TLS）**。

→ plain HTTP 发到 TLS 端口 → nginx 返回 **400**（"plain HTTP request sent to HTTPS port"）
→ wait_ready 收到 400 → 不在重试白名单 {502,503,504} → 立即停止

**这解释了 W4 的 400**（.171 诊断信封 http_status=400@08:44:46）——400 来自协议不匹配，非 IP 白名单。
