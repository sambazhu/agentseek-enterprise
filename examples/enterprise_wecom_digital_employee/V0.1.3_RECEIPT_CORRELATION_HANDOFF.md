# I06 双用户工具事件与投递回执关联

## 范围与判定

| 项 | 合同 |
| --- | --- |
| 基线 | ff8721e，I05 归档后；业务 wheel 和节点运行源码零变化 |
| 判定上限 | RECEIPT_CORRELATION_OFFLINE_PASS；仅合成离线链，不代表真实网关日志验收或 I01–I07 全完成 |
| 接线 | 沙箱三个异步工具与 deliver_workspace_file 共用 observed 包装器；列表工具不记录文件列表 |
| LangChain 边界 | wraps 保留工具签名；runtime 不进入模型参数；不新增模型可填写的 scope/request/event/recipient 参数 |
| 日志通道 | 既有 loguru INFO sink；不加 handler，不改根日志级别，不读取 .env |
| 返回值变化 | read_sandbox_csv_result 新增已核定 artifact_ref；其余工具结果、状态机与去重键不变 |
| 现场 | 零 SSH、部署、重启、guest 创建、实发、清理；无需打 wheel 或交 .172 |

## 事件字段（schema=1）

| 字段 | 来源/语义 |
| --- | --- |
| 前缀 | sandbox_tool / workspace_delivery_tool；由固定工具名映射，非输入值 |
| schema/name/event/phase | 版本 1；固定工具名；每次调用独立 UUID hex；start/complete/failed/cancelled |
| call_sha256 | ToolRuntime.tool_call_id 的 UTF-8 SHA256；缺失为 absent；模型调用 ID 不可信作授权，也可能跨用户重复 |
| scope_sha256 | 仅 runtime.context.enterprise 的 tenant/user/session；SHA256("scope-v1:" + ensure_ascii=true、紧凑 JSON 三元数组)；不从可变 state 补身份 |
| state/current | 固定状态白名单或 other；matches_current_request is True；仅 complete 常规路径有值 |
| request_sha256 | 工具结果 request_id 的 UTF-8 SHA256；保留既有算法 |
| attempt_sha256 | 工具结果 attempt 字符串的 SHA256；不是原 attempt 直接输出 |
| artifact_sha256 | artifact_ref 字符串的 SHA256；**不是 CSV 内容摘要** |
| file_ref_sha256 | workspace file_ref 字符串的 SHA256；**不是内容摘要** |
| delivery_sha256 | 投递回执 delivery_id 字符串的 SHA256；可对私有 NFD 账本同 ID 重算 |
| reused | 投递结果 reused_receipt 的 True/False；不可用时 absent；不等于用户实收 |
| absent | 缺失、空值、非字符串、超过 4096 字符或不可 UTF-8 编码的 ID，不补猜值 |

## 提取门禁

| 事件 | 关联字段条件 |
| --- | --- |
| 沙箱完成 | request/attempt/artifact 只取实际工具结果，不取模型入参；state/current 用白名单 |
| 沙箱 file_ref | I05 workspace.association.state=verified，且 request/attempt/artifact 三项与外层结果逐项相同 |
| 原始 CSV 读取 | 可关联 request/attempt/artifact；没有工作区关联时 file_ref_sha256=absent，不把读字节当回写证明 |
| 投递完成 | 仅 api_accepted/upload_failed/uncertain 且有 delivery_id 时记录已选 file_ref 摘要；工具内部已经校验真实选择 |
| 投递拒绝 | 不记录被拒的外用户 file_ref；file/delivery 摘要 absent，不把提议记录为核验通过 |
| 取消/异常 | 保留同 event/call/scope，记录 cancelled/failed 后原异常抛回；不记录异常类型正文、参数、回执猜值 |
| 观测提取异常 | complete state=other；原业务结果返回，不因日志错误触发发送重试 |
| sink 异常 | 不改变工具返回或副作用；不向另一日志通道输出原异常；可能无日志 |

## 对账关系与限制

| 对账 | 可以证明 | 不能证明 |
| --- | --- | --- |
| 同 event 的 start/terminal | 一次包装器调用的起止观测；call/scope 一致 | HTTP 是否发送、用户是否收到 |
| scope+request+attempt 摘要与私有业务账本重算 | 该观测结果对应哪一条任务记录 | 日志本身构成执行授权或替代账本 |
| request/attempt/artifact→file_ref | 由 I05 已验证关联返回的任务与文件副本关系 | 每个任务独占一个文件；created_at 是任务身份 |
| 同 scope+file_ref 的投递事件 | 哪份文件对应哪个 delivery 回执 | 该次投递必由某次任务引起；NFD 无 request/attempt 归属字段，必须保持 absent |
| 同 delivery 摘要、不同 event、reused=true | 重复索取返回既有回执 | 新发送发生；api_accepted 也不是用户实收确认 |
| 明确重发 | 新真实入站消息按既有合同生成不同 key，日志呈现不同 delivery 摘要 | 模型可以铸造重发授权 |
| 双用户同 call ID | scope/event 仍区分；不得只用 call ID 连接日志 | call ID 全局唯一或可信 |

## 隐私与覆盖限制

| 项 | 边界 |
| --- | --- |
| 日志正文 | 固定字段、固定状态、布尔和摘要；不含身份明文、文件名、路径、原始调用 ID、指令、CSV、凭据、收件人或异常正文 |
| 摘要 | 属可关联的假名化标识，不是匿名化或授权令牌；日志仍需访问控制与保留策略 |
| Logger 来源 | 模块名改为 enterprise_wecom_digital_employee.tool_observation；消息前缀保留 sandbox_tool，新增 workspace_delivery_tool；若运维有模块名过滤，采用单须另行核查，不能沿用旧模块过滤假定 |
| 未覆盖 | 长连接认证前、工具 schema 验证前、进程硬杀、线程取消后是否真正停止、实际生产 sink、Langfuse 现场接口 |
| 取消 | 仅证明等待调用取消；不能证明线程/网络副作用停止或授权重试 |
| 日志缺失 | 可能因过滤、sink 故障、硬杀或未进入包装器；不能反推“没有执行/发送” |
| 关联不唯一 | 多任务可共享一份文件；本候选不增加任务级发送授权、不自动选最新任务、不伪造因果关系 |
| 采用/回退 | 另批网关操作单；既有 NFD 回退硬门、历史保全要求不变 |

## 离线矩阵

| 场景 | 项数 | 证据范围 |
| --- | --- | --- |
| 双用户查询→投递→私有回执 | 1 | 实际业务库/I05 关联/通道 capability/NFD 账本；MockTransport 模拟上传和发送；任务成功记录合成预置，非真实 guest |
| 同文件多任务 | 1 | 两组 request/attempt/artifact、同 file_ref、复用同 delivery；无虚构任务投递因果 |
| 成功/uncertain 回执复用及明确重发 | 2 | 同 key 新 event + reused=true；明确重发新 key；不确定不自动重发 |
| 跨用户拒绝 | 1 | 不记录外用户 file_ref，零模拟 HTTP 调用 |
| 取消/BaseException | 2 | 成对事件与原控制流保留，无异常正文或猜测回执 |
| sink 故障/字段提取故障 | 2 | 不改变成功结果、不追加发送 |
| 上传失败 | 1 | upload_failed 与回执关联、零发送、异常正文不入日志 |
| 模型参数合同 | 1 | 四工具参数无 runtime 身份/关联字段 |
| 非法/超长/不可编码 ID | 5 | 仅 absent，不抛出或泄露 |
| 白名单+state 身份反证 | 1 | 不从 state 补 scope；未知状态 other；正文丢弃；单行长度有界 |
| run+read 与实际 attempt | 1 | 既有进程内模拟 provider；关联摘要匹配实际库记录，非真实沙箱 |
| 新专项 | 18 | 18 passed |
| 原日志/隔离/NFD 回归 | 已纳入全套 | 旧 start/terminal 语义、默认 stdlib 无 handler 时走 loguru、无重复 sink、流式守卫、判重保留 |
