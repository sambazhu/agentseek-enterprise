## 三、事件字段清单（脱敏口径，修正后）

工具事件（`tool_observation.py`）每条仅含：

| 字段 | 来源 | 说明 |
| --- | --- | --- |
| `name` | 固定工具名 | 白名单三沙箱工具 |
| `event` | 服务端随机 uuid hex | 本次调用标识（非模型可控） |
| `phase` | start / complete / failed / cancelled | 白名单 |
| `call_sha256` | sha256(runtime.tool_call_id) | 缺失记 absent |
| `state` | 结果状态白名单 | succeeded/failed/reconciling/not_executed/… |
| `current` | matches_current_request is True | 布尔 |
| `request_sha256` | sha256(request_id) | 请求摘要 |

**不含**：工具参数、CSV 正文、结果正文、文件路径、身份明文、凭据、下载链接、投递句柄、异常正文。

## 四、关联口径（修正后）

- 工具事件的 `request_sha256` 与回执的 `delivery_id` **各自独立**——两者分别含 request_id/attempt 摘要作为各自主键，**不存在执行→投递的自动串联字段**；
- **文件关联不等于任务触发投递**：workspace_binding 关联 attempt↔file_ref 是事实记录，不构成投递触发（投递仍须用户明确索取）；
- **日志不替代账本或用户实收**：工具事件是观测层脱敏信号，不是权威判定依据（权威=双侧 store attempt 行+用户实收确认）。

## 五、重点核验结果（18 项）
