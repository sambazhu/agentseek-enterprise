# 勘正与两端汇总（.171 Linux CC，2026-09-19；原报告 6a7f93c8 未修改，本件为独立附件）

## 一、Codex 审阅勘正（对原报告）

1. **"12 字段"→11 项勘正**：business_service 顶层精确字段集为 **11 项**：schema、approved、bind_host、bind_port、certificate_file、private_key_file、permits_file、permits_sha256、store_directory、workspace_directory、plans（候选代码 load_config 精确集合校验）。原报告 §三"12 字段契约"为文字计数错误之疑——**以 .172 只读核对草案实字段为准**：若草案恰为上述 11 项=仅计数笔误（说明实际字段一致即可）；若草案确有额外字段=另存修订版并重新记录摘要。不得凭字段数量推定完整配置通过。
2. **"零变更"表述收窄**：明确为"**已生成准备材料，运行配置和服务未变更**"。
3. **G1/G2 结论措辞**：应为"**本轮节点准备未发现新的运行代码问题；网关文件输入、身份绑定及用户文件访问是否存在接线缺口，待事实包核对**"。
4. **待批准性质重申**：13100 端口、专用 CA、64 字符随机十六进制 token、业务目录与新监督方案均为**待批准建议**；端口空闲与 INPUT 默认 ACCEPT 是**采集时点事实**；规则实施顺序、作用范围及恢复办法纳入最终部署方案，本轮不实施。
