# 沙箱业务纵向切片

## 范围与证据

| 项目 | 状态 / 约束 |
| --- | --- |
| 首个业务 | UTF-8 CSV 的 `group,amount` 分组求和；输出 `group,total` |
| 输入上限 | 32768 字节、1000 行；有限 Decimal；金额绝对值不超过 1e12、至多六位小数 |
| 执行程序 | 固定程序；模型选择工具和输入引用，不生成任意 shell/Python |
| Agent 循环 | 真实 DeepAgent 图、脚本化模型、本地合成 provider 的离线测试；不是活体模型选择验收 |
| 落盘 | 私有 SQLite 中保存任务与结果字节，校验摘要、读回，再执行销毁 |
| 清理确认 | DELETE 被接受不足以记成功；另需 lifecycle closeout 确认目标不存在 |
| 失败 | 创建/清理不确定为 `reconciling`；已落盘结果保留；不自动重试或重建 |
| 默认启用 | 禁用。无环境变量自动启用；由可信 composition 显式注入工具 |
| 生产与现场 | 未部署、未创建 guest、未调用真实模型或 Cube、未改历史额度和监督 |
| R1 关系 | 不替代 A/B/X1 矩阵；旧 A 批准不授权 CSV 执行或主动销毁 |

## 接口

| 接口 | 责任 |
| --- | --- |
| `csv_pilot_tools(...)` | 组合已认证身份、当前上传文件、任务批准、结果存储、provider |
| `SandboxGrant` | 可信服务端提供的精确任务许可：身份、会话、文件、指令摘要、请求 ID、期限 |
| `run_sandbox_task(input_ref, instruction)` | 模型可见参数仅两项；身份与路径不由模型指定 |
| `read_sandbox_csv_result(artifact_ref)` | 按所有者读取已落盘结果，不创建 guest；可读不代表清理已确认 |
| `build_spec(sandbox_tools=...)` | 显式接入已有网关 Agent；Work registry 存在时另需 profile grant |
| `BusinessStore` | 同库未解决任务阻止新创建；相同请求不重复执行；跨所有者不可读 |
| `LifecycleBusinessProvider` | 同机读取受信创建链，创建前绑定业务批准，创建后读取密封回执 |
| `ApprovedCsvSessionFactory` | 绑定输入/指令摘要、创建 binding、vault、监督与控制面配置 |
| `business_cube_session` | 隔离子进程内有界执行固定程序或终止；无重试、无 host shell 回退 |

## 同机适配器前提

| 条件 | 说明 |
| --- | --- |
| 主机 | Linux root；审批、vault、监督、身份 pins 与安装入口位于同一主机 |
| 安装 | worker 使用当前解释器 `-I -m`；仅设置源码 PYTHONPATH 不足以供子进程导入 |
| 模板 | guest 必须提供 python3 及所需标准库；真实模板能力尚未验证 |
| 平台 | v0.7 形态、loopback CubeProxy 13080、guest envd 49983、traffic token |
| envd | 当前适配器只接受 envd token absent/null；不声称验证 envd token 身份门 |
| 期限 | 执行前至少留 30 秒；worker 执行预算 25 秒、终止预算 10 秒；监督 120 秒不延长 |
| 控制面 | HTTPS CA 验证；业务批准需另含主动终止许可 |
| 中断 | 线程取消不等于远端停止；独立监督兜底；reserved/reconciling 状态不自动解除 |
| 凭据 | 只进入私有批准文件和 worker 私有读取；不作为模型参数、返回值或日志正文 |

## 完整业务验收尚缺项

| 顺序 | 交付 / 验收 | 不可替代的证据 |
| --- | --- | --- |
| 1 | `.171 → .172` 已认证业务 broker，或另批同机隔离试验拓扑 | 不能把本地 provider 直接当远程网关；不搬凭据到模型侧 |
| 2 | 服务端任务批准签发与消费接线 | 现为显式 callback；模型不得自行构造 grant |
| 3 | 业务候选安装闭包与 Linux 复验 | 现有 36 模块/9 入口 R1 清单不包含本业务适配器 |
| 4 | 活体问题触发与固定 CSV 计算 | 模型实际选择工具、真实创建/计算、字节结果符合预期 |
| 5 | 企微文件交付接线 | 当前返回 CSV 工具内容和结果引用，不等于附件上传交付 |
| 6 | 生命周期最终验收 | 持久化读回、目标消失、清理失败不报成功、普通问题不创建 |

## 不变量

| 保留项 | 约束 |
| --- | --- |
| production / 标签 | 不变 |
| 旧 A run / quota / fence / 回执 | 不变；不得换目录规避历史额度 |
| W0 / 窗口 | 旧窗口不续用；本文件不提供任何现场授权 |
| 现场分工 | `.172` 独占执行；`.171` 备料、摘要核验、归档；Codex 不 SSH |
