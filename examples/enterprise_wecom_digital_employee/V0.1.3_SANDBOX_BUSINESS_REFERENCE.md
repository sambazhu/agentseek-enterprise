# 沙箱业务纵向切片

## 工作区返回口径（2026-09-18 用户澄清）

| 阶段 | 结果 |
| --- | --- |
| 沙箱计算 | guest 中固定程序生成 `summary.csv`，读取并导出文件字节 |
| 节点持久化 | 私有账本保存字节，沙箱外用户隔离工作区保存文件及 manifest，摘要读回后才销毁 |
| 网关返回 | 经 HTTPS 校验结果，镜像到现有 `LocalFileStore` 的用户/会话文件区，返回文件引用 |
| 对话响应 | 结果说明、工作区文件名和引用；可选返回短期浏览器下载链接，没有企微媒体上传或附件发送 |
| 工作区边界 | 当前为固定 CSV 不可变输出；不是通用 M3 `WorkspaceRevision` 提交/恢复验收，前端文件列表可见性尚未实测 |
| 勘正 | 上版把企微附件交付列为缺项，超出任务范围；本轮删除，新增发送适配未提交、未部署 |

## 范围与证据

| 项目 | 状态 / 约束 |
| --- | --- |
| 首个业务 | UTF-8 CSV 的 `group,amount` 分组求和；输出 `group,total` |
| 输入上限 | 32768 字节、1000 行；有限 Decimal；金额绝对值不超过 1e12、至多六位小数 |
| 执行程序 | 固定程序；模型选择工具和输入引用，不生成任意 shell/Python |
| Agent 循环 | 真实 DeepAgent 图、脚本化模型、本地合成 provider 的离线测试；不是活体模型选择验收 |
| 落盘 | broker 必需 `CsvWorkspace`；文件/manifest 原子不可覆盖、0600、fsync、读回；SQLite 保留任务与结果 |
| 清理确认 | DELETE 被接受不足以记成功；另需 lifecycle closeout 确认目标不存在 |
| 失败 | 创建/清理不确定为 `reconciling`；已落盘结果保留；不自动重试或重建 |
| 默认启用 | 禁用。默认 agent spec 不变；另选 `sandbox_spec.build_spec` 且提供私有、钉摘要的批准配置 |
| 生产与现场 | 未部署、未创建 guest、未调用真实模型或 Cube、未改历史额度和监督 |
| R1 关系 | 不替代 A/B/X1 矩阵；旧 A 批准不授权 CSV 执行或主动销毁 |

## 接口

| 接口 | 责任 |
| --- | --- |
| `csv_pilot_tools(...)` | 组合已认证身份、当前上传文件、任务批准、结果存储、provider |
| `remote_csv_tools(...)` | 网关上传已批准文件字节，一次请求驱动节点全链；结果回用户文件工作区 |
| `SandboxGrant` | 可信服务端提供的精确任务许可：身份、会话、文件、指令摘要、请求 ID、期限 |
| `run_sandbox_task(input_ref, instruction)` | 模型可见参数仅两项；身份与路径不由模型指定 |
| `read_sandbox_csv_result(artifact_ref)` | 按所有者读取已落盘结果，不创建 guest；可读不代表清理已确认 |
| `build_spec(sandbox_tools=...)` | 显式接入已有网关 Agent；Work registry 存在时另需 profile grant |
| `BusinessStore` | 同库未解决任务阻止新创建；相同请求不重复执行；跨所有者不可读 |
| `BusinessBroker` | 只接受预置 permit 的精确请求和输入摘要；不接受远程创建批准、命令或主机路径 |
| `BusinessHttpClient` | HTTPS CA 校验、独立 broker token、有限响应；无自动重试、无重定向 |
| `business_service` | 明确批准配置下才启动独立私网 IPv4 TLS 服务；不在 import 时监听 |
| `ApprovedGrantCatalog` | 网关私有批准目录；同一可信身份/会话须恰一项有效许可，歧义拒绝 |
| `RemoteCsvRunner` | 先落本地意图再提交；响应丢失保留 reconciling，恢复只读远端账本 |
| `get_sandbox_task_result()` | 本人最近任务只读恢复、同步结果；不创建、不执行、不发送附件 |
| `WorkspaceDownloads` | .171 私有授权库绑定输出文件；默认关闭，启用后签发短期链接，浏览器读取前校验范围/摘要/有效期 |
| `/ai-server/workspace-files/{link_id}` | 网关上的工作区打开页；独立于 Work 下载模式；URL fragment 授权，经 POST redeem 下载 summary.csv |
| `CsvWorkspace` | 固定 `summary.csv` 与绑定 manifest；目录为所有者/请求隔离，不向模型返回主机路径 |
| `LifecycleBusinessProvider` | 同机读取受信创建链，创建前绑定业务批准，创建后读取密封回执 |
| `ApprovedCsvSessionFactory` | 绑定输入/指令摘要、创建 binding、vault、监督与控制面配置 |
| `business_cube_session` | 隔离子进程内有界执行固定程序或终止；无重试、无 host shell 回退 |

## 同机适配器前提

| 条件 | 说明 |
| --- | --- |
| 主机 | Linux root；审批、vault、监督、身份 pins 与安装入口位于同一主机 |
| 安装 | worker 使用当前解释器 `-I -m`；仅设置源码 PYTHONPATH 不足以供子进程导入 |
| 模板 | guest 必须提供 python3 及所需标准库；真实模板能力尚未验证 |
| 平台 | v0.7 形态、loopback CubeProxy 13080、guest envd 49983、traffic token |
| envd | 当前适配器只接受 envd token absent/null；不声称验证 envd token 身份门 |
| 期限 | 执行前至少留 30 秒；worker 执行预算 25 秒、终止预算 10 秒；监督 120 秒不延长 |
| 控制面 | HTTPS CA 验证；业务批准需另含主动终止许可 |
| 中断 | 线程取消不等于远端停止；独立监督兜底；reserved/reconciling 状态不自动解除 |
| 凭据 | 只进入私有批准文件和 worker 私有读取；不作为模型参数、返回值或日志正文 |

## 状态与恢复

| 状态 | 行为 |
| --- | --- |
| `succeeded` + `workspace.available` | 节点文件已持久化、沙箱不存在已确认、网关文件区可读 |
| `workspace_pending` | 节点执行成功且已清理，但网关文件回写失败；只读取回，不重新执行 |
| `download_pending` | 网关文件已保存，但链接签发失败；查询结果可重新签发，不创建沙箱 |
| `workspace.download.available` | 打开链接已签发；真实反代与用户浏览器可达性另行实测，链接在有效期内可重复下载 |
| `reconciling` | 结果或清理不确定；相同请求不会再创建，同库新创建被阻止 |
| broker 返回 `not_found` | 不自动重发输入；保留本地未知状态供核对 |
| 过期许可 | 不能开始新任务；节点允许持同一凭据读取该请求历史结果 |

## 现场接线前检查

| 检查 | 要求 |
| --- | --- |
| 工作区 | 节点权威文件区位于 guest 外；网关文件区沿用 `FilesSettings`；不能把临时沙箱目录当持久区 |
| 文件身份 | 文件 `employee_key/session_key` 必须与可信 runtime 一致；企微 userid 与 OA 账号不一致时不得猜测映射 |
| profile | Work registry 模式还需 `run_sandbox_task` grant；启用 spec 不等于授权任意任务 |
| 凭据 | `.171` 仅持 broker 调用 token；Cube API key、vault、监督私有材料保留 `.172` |
| 范围 | 不启用企微附件、不改生产默认 spec、不沿用历史 A 额度、不自动创建新 run |

## 不变量

| 保留项 | 约束 |
| --- | --- |
| production / 标签 | 不变 |
| 旧 A run / quota / fence / 回执 | 不变；不得换目录规避历史额度 |
| W0 / 窗口 | 旧窗口不续用；本文件不提供任何现场授权 |
| 现场分工 | `.172` 独占执行；`.171` 备料、摘要核验、归档；Codex 不 SSH |
