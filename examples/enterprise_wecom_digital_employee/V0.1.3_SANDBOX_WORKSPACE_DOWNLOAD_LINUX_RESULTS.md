## 四、用户可访问 HTTPS 下载路径与反代核对（差分实证）

路由合同：`ROUTE_PATH=/ai-server/workspace-files`；GET `/{link_id}`=下载页（token 走 URL fragment，不进 HTTP）；POST `/{link_id}/redeem`；MODE=disabled 时不注册；签发绑定 tenant/user/session+落盘元数据+文件摘要；TTL 默认 600s≤3600s≤保留期；link_id 形如 `workspace_[a-f0-9]{64}`。

**反代现状（test.wkzq.com.cn:9443 → .60 nginx，2026-09-19 实测）**：

| 路径 | 结果 | 判读 |
| --- | --- | --- |
| `/wecom/app/x` | 404 **application/json**（与直打 :12001 逐字节同） | 该 location 正确转发 .171:12001 ✅ |
| `/ai-server/workspace-files/x`、`/ai-server/artifacts/x` | **502 nginx html** | `/ai-server/` **存在 location 但上游已死**（疑指旧 :12000——09-10 传输切换后死亡；或指其他失效上游） |
| `/random-unknown-path` | nginx 静态 404 | 无匹配 location |
| 直打 `http://127.0.0.1:12001/ai-server/...` | 网关 FastAPI JSON 404 | 网关本体路径空间正常（未注册=mode disabled，预期） |

**结论**：用户下载链接的公网 HTTPS 形态**当前不通**——需 **.60 nginx 变更**：将 `/ai-server/`（或精确 `/ai-server/workspace-files/`）location 重指/新增转发至 `192.10.50.171:12001`，放行 **GET+POST**（redeem 为 POST，body 承载 token）。.60 为管理员侧（仅密码 SSH），该变更列入最终工单批准项；变更前 BASE_URL 无法按 https 公网 origin 工作。**不将文件区作静态目录暴露**；对话正文中的完整链接视为短期访问凭证（不记录链接全文/redeem 请求体）。

## 五、最终部署配置草案（未写入运行 .env）

```dotenv
AGENTSEEK_WORKSPACE_DOWNLOAD_MODE=signed_link
AGENTSEEK_WORKSPACE_DOWNLOAD_BASE_URL=https://test.wkzq.com.cn:9443/ai-server/workspace-files  # 拟议（待 .60 nginx 变更批准后定稿）
AGENTSEEK_WORKSPACE_DOWNLOAD_GRANTS_DIR=/var/lib/agentseek/workspace-downloads  # 网关 UID 所有 0700，程序建 0600 授权 SQLite
AGENTSEEK_WORKSPACE_DOWNLOAD_TTL_SECONDS=600
```

AGENTSEEK_WORK_ARTIFACT_DELIVERY_MODE 保持原值（disabled）；网关 Channel 与 sandbox_spec 同 env、同 FilesSettings 根目录。
